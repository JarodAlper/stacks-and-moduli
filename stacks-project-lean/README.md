# Stacks Project results

This directory holds Lean formalizations of results that *Stacks and Moduli* cites from the
[Stacks Project](https://stacks.math.columbia.edu). Files are organized as
`StacksProject/<Chapter>/<Section>/<label>.lean`, and each module docstring names the Stacks
Project tags it formalizes, so every statement can be compared with the original at
`https://stacks.math.columbia.edu/tag/<TAG>`.
